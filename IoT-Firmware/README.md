# CIBYP IoT TRNG

固件已迁移到 **Rust + ESP-IDF 6.1**，不再使用 Arduino。应用设置提供 USB 设备识别、随附镜像 SHA-256 校验、内置烧录、进度和错误反馈。

新版保留并现代化离线 WebUI、REST 抽牌接口与 WebSocket。首次启动为空密码的配置热点，必须先设置自己的密码才能抽牌，此后使用 WPA2。固件升级通过应用内 USB 烧录完成。开发镜像用于塔罗和随机数；生产安全加固、钱包硬件熵与真正的硬件钱包是不同能力。

安装、构建、串口协议、芯片支持与不可逆 eFuse 的边界见 [固件说明](CIBYP-TRNG/README.md)。当前没有实物烧录或物理攻击验收记录；S31 为预览支持。
