# Could I Be Your Partner 1.9.0

1.9.0 正式版整合此前预览版本的桌面、终端与浏览器体验。本次发布增加官方 OpenCode AI SDK 请求引擎、主机 Tor 网络隐私设置，并修复与证书信任有关的问题。

## 主要变化

- 青春 / 专业两套界面，共用 GUI、TUI、WebUI 后台、设置、会话和工作区。
- 模型池可选择 OpenCode AI SDK 请求引擎，工具执行与权限继续由 CIBYP 管理；模型可用性由提供商决定。
- 网络隐私设置支持内置 Tor、网桥和连接进度；未连接时阻止范围内的请求。HTTP 重定向的每一跳都重新检查路由，避免本地地址跳转造成外部请求直连。
- 提供商明确拒绝访问、认证失败或隐私连接未就绪时停止无效重试，保留原始错误信息。
- VM 在冷启动及快照恢复后验证 CA 撤销状态，升级证书包，修复 Debian 安全更新源与定时器。
- 内置 CLI Node 升级至 24.22.1；Tor / OpenSSL 升级至 0.4.9.14 / 3.5.9；更新 DOMPurify、markdown-it、Undici 等依赖，恢复 IMAP 证书校验。
- GeoGebra 离线绘图包锁定版本和 SHA-256，六平台共用经过校验的官方归档，避免 Windows 构建被下载站连接超时阻断。

## 安装与更新

桌面安装包和 npm 启动器均从本 Release 获取对应平台产物。npm 启动器维持独立版本 `1.0.1`，无需重复发布 npm 包即可获取新版 App。可使用 `cibyp --channel=stable` 选择正式版通道，或在应用中执行 `/update`。

## 已知安全限制

**本版本尚未消除全部原生运行时漏洞。** Electron 43.8.3 的内置 Node 24.22.0，以及 Debian VM 的 Node 分支，仍有等待供应商修复的已知问题，包括近期 Brotli/TLS 相关漏洞。CA 信任修复不等同于修复这些原生漏洞；npm 审计仍有旧图像依赖链的中危告警。具体影响、适用条件及验证范围见[安全审计报告](https://github.com/B5-Software/Could-I-Be-Your-Partner/blob/v1.9.0/docs/security-audit-2026-10-23.md)。
