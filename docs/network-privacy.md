# OpenCode AI SDK 与 Tor 网络隐私

## OpenCode 请求 SDK

在设置 → 模型与连接 → OpenCode 请求引擎中选择 **OpenCode AI SDK**。模型池编辑器也可为单个 Zen / Go 条目选择引擎，支持在会话中切换，并随会话配置恢复。

此接入使用官方仓库的 [`@opencode/ai` 2.1.0](https://github.com/anomalyco/opencode/tree/dev/packages/ai) 负责协议编码与流式解析。CIBYP 保留会话、上下文、工作区、工具、审批和用量统计，不启动另一套 OpenCode Agent 或读取其凭据目录。SDK 不执行工具；返回的调用继续由 CIBYP 执行。

SDK 路径不追加 OpenCode 兼容占位工具，不改写 CIBYP 系统提示词，也不自动声明自己是 OpenCode CLI。用户原有的引擎选择保持不变。上游的模型、地区、网络或客户端限制仍由提供商决定；明确拒绝会停止自动重试。

## Tor 设置

打开设置 → **网络隐私**，启用“通过 Tor 发送主机网络请求”，然后点击“连接 Tor”。默认关闭；可选择随后台启动连接。GUI、WebUI 与 TUI `/config` 共享相同配置，TUI 分类中也提供连接、停止和状态操作。

- 使用现有打包 Tor 二进制、SHA-256 验证下载和网桥解析器。支持 obfs4、Snowflake、WebTunnel 和 meek；可填入自己的网桥，或选择内置 meek 配置。
- 隐私出口与手机远控的洋葱服务拥有独立状态和数据目录。连接隐私出口不会开启 WebUI、洋葱服务或控制端口；SOCKS 只绑定 `127.0.0.1`。
- 保护范围为主机统一 fetch 发出的 HTTP/HTTPS 请求，包括常规 AI 请求、OpenCode AI SDK、模型目录和网页工具。域名通过 SOCKS 交由 Tor 解析。普通代理的 bypass 列表及单次请求的 dispatcher 不会绕过这层保护。
- 本地回环连接保持直连。外部浏览器、终端子进程、SMTP/IMAP 和 DNS/ping 等原始网络接口不在此保护范围内。
- 启用保护但 Tor 未连接、正在准备或断开时，范围内的请求会被阻止，不会自动改为直连。停用这个设置才会恢复原有网络代理行为。
- 只有下载已锁定哈希的官方 Tor 运行时属于启动例外，通过原有网络配置获取，以避免“必须先连 Tor 才能下载 Tor”的循环。

Tor 隐藏网络来源，不会隐藏请求里的账号、API Key、代码或其他识别信息。该功能不提供自动换出口或对服务限制的自动恢复。

## 验证范围

本地测试覆盖实际 SDK HTTP/SSE 请求、工具调用、用量、取消、提供商拒绝、SOCKS 握手、代理端域名解析、断线阻止直连、隐私与远控隔离，以及共享设置页面。使用真实打包 Tor 验证了隐私配置语法。真实 Tor 公网连接和特定地区的网桥可用性取决于用户网络，未宣称已验证。
