# MCP 配置与连接

设置 → MCP 的每张服务卡片提供编辑、连接/断开和删除按钮。编辑会回填现有配置，可修改名称、连接方式、stdio 命令/参数/环境变量/工作目录，或 Streamable HTTP 的 URL/请求头。参数必须是字符串数组，环境变量和请求头必须是值为字符串的对象；同名配置拒绝保存。取消编辑不保存，并清空草稿中的凭据。

保存后，已连接的服务会先关闭旧连接，再按新配置重连并刷新工具。断开的服务保持断开。重新连接失败仍保留配置，卡片显示具体错误与可展开的诊断详情，可编辑后重试。环境变量和请求头中的凭据在诊断中遮罩。

连接卡片依次显示启动连接、协商协议、确认初始化、加载工具的阶段和进度条。进度对应已完成的阶段，不是时间估计。可随时点击断开取消；初始化有请求超时和总体超时，重复点击连接共用同一个连接请求。HTTP 初始化通知完成后才请求工具，SSE 同时支持 LF 和 CRLF 换行，工具分页循环会报错停止。

HTTP 会话过期时重新初始化连接，失败的工具调用返回错误，由 Agent 决定是否重试；不会自动重放可能修改文件的工具。可选 HTTP 事件流中断后有限次重连，流不支持时不影响普通工具请求。

协议依据：[MCP 生命周期](https://modelcontextprotocol.io/specification/2025-06-18/basic/lifecycle)、[Streamable HTTP 传输](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)。
