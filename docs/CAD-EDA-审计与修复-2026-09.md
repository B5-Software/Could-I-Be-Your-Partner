### B. P1（规范错误 / 契约 / 功能）

- **Gerber/Excellon**：`%FS/%MO/%AD/%LP/M02` 结构核验通过；Excellon 补 `FMAT,2`、`G90`、`G05`、`T0`、`;TYPE=PLATED/NON_PLATED`；thermal 宏图元 7 参数个数修正（5）与参数 X 分隔；`drawPad/clearPad` 180° 不再交换宽高；`_coord/_fmtD` 非有限值防护；钻孔输入坐标/孔径有限性校验。
- **PnP/BOM**：PnP 的 Y 与 Gerber/钻孔一致（取反）；全字段 `csvEsc`；UTF-8 BOM；BOM 分组键改 JSON（值含 `|` 不再拆错）。
- **KiCad 导出**：补齐 Mask/Paste 层声明（34/35/38/39）；ref/value/net 的 s-expr 转义。
- **SVG 原理图导出**：ref/value/网络标签 XML 转义（此前 `&` `<` `>` 产出非法 XML）。
- **pcbeda UI**：命令行 `await window.pcbExecuteCommand`（此前恒走失败分支）；文本导出生成失败报错而非写空文件；OBJ 扩展名/mtllib/MTL 失败上报；PNG 空数据报错 + 导出目录自动创建。
- **PCB 编辑器**：单击不再吸附/置脏（3px 位移阈值 + 撤销空快照）；`Ctrl+F/Ctrl+V` 等不再被裸键吞掉；zone 离屏画布宽高同时检查。
- **原理图同步**：只清理网表中出现过的元件，保留安装孔/测试点的手工网络。
- **CAD**：`fnum` 非有限值防护 + 禁止科学计数法；`extend` 不再把线段"缩短"；`_translateObj` TEXT 双倍位移修复、POINT 可移动；INSERT 缩放 `0/NaN` 不再被 `||1` 吞掉；DIMENSION 导入缺 11/21 时回退 10/20（不再整条丢弃）。
- **清理**：`cipypcad:writeFile` 通道与 preload 暴露删除（XSS 升级点，全项目无调用方）。

## 二、待处理（已确认，按优先级）

### B1（需实机核对再动）B 面「镜像+旋转」约定

- 位置：`pcb-model.js` `allPads`、`pcb-gerber.js`（丝印/位号/PnP）、`pcb-render.js`、`pcb-sch-render.js`、`pcb-io.js`。
- 现状：先镜像局部 X 再按 `+rot` 旋转（自洽：渲染/Gerber/DRC/导出同一公式，且有测试锁定）。
- 疑点：与 KiCad 后置元件旋转语义是否一致（`R(θ)·M` vs `M·R(θ)`）。
- 处理建议：用真实 KiCad 打开一个 B 面 90° 元件文件对比；确认后再统一修正（5 处需同时改）。

### B2 CAD / DXF（`src/renderer/js/cipypcad.js`）

- 导入：OCS/extrusion（210/220/230）未处理；LWPOLYLINE 的 bulge(42) 丢失；HATCH 实体恒被丢弃（`__hatch_placeholder__` 后被过滤）；`$INSUNITS` 单位换算缺失；二进制 DXF 未识别；BLOCKS 内 POLYLINE/VERTEX 未做后处理；未支持实体无告警/计数。
- 导出：ELLIPSE 退化为"平均半径圆"且丢 rotation；ARC 起止角未归一化；HEADER 缺 `$INSUNITS/$DWGCODEPAGE`、`$EXTMIN/$EXTMAX` 恒为 0；TABLES 缺 LTYPE（引用了未定义的 CONTINUOUS）；退化图元（零长线/非正半径）未过滤；颜色哈希映射到 1-8 号 ACI。
- 几何/命令：`rect` 旋转按对角线重构（应取 4 角点旋转）；`mirror` 角度用 `θ'=2φ−θ`；`fillet` 切点距离应为 `r/tan(θ/2)`（当前以交点为圆心）；`join`/`break` 缺拓扑校验；弧/角度统一归一化工具；捕捉（snap/osnap）未实现（文档宣称可用）；`_pickAt` bbox 拾取忽略图层锁；fit zoom 无下限。
- 文件/UI：写盘非原子（建议 tmp+rename）；大文件同步读写阻塞；BOM 剥离；`loadJSON` 缺 type 白名单/数值校验/重复 id 检查；图层颜色 `innerHTML` 注入（配合已删除的 writeFile 通道曾是 XSS）；图层锁定未生效；锁图标与眼睛图标绑定同一行为；Delete 键与图层 UI 无撤销；`tools-def.js` 命令语法与实际实现不符（会诱导 LLM 生成无效命令）；GUI 无"打开工程"入口；导入 DXF 是追加式、无询问。

### B3 EDA 内核（`src/renderer/js/pcbeda/`）

- 模型：`net id` 缺失（改名不级联、删元件残网）；`CONNECT_TOL=1.5mm` 过大（与 ERC 0.01mm 不一致，平行不同网络可能被静默并入）；T 型连接漏判（`trkpt` 被排除）；zone 连通只用代表元；`addTrace` 未拒绝 <2 点（DRC 会抛）；`_normalizeProject` 弱校验（错误类型直接 `.map` 崩溃）；重复 ID 不去重；`board()/sheet()` 空数组返回 undefined。
- DRC：pad 间距用外接/内切混合近似（旋转/长条焊盘误报漏报）；zone/keepout 完全不检查；板边只采样顶点（中段穿出漏检）；规则项缺差分对/孔到铜/丝印/阻焊等；增量 DRC 的 pad key 正则失效；短路无独立类型。
- 自动布线：rip-up 结果与返回值不一致；45° 优化后仅网格采样校验（可能切入间距区）；选项数值无校验（0/NaN 会生成 0 宽走线）；NPTH 被当铜阻挡；`routeSingle` 未真正约束两点；性能（单条网络 A* 仍可能卡 UI、无取消）。
- 封装/符号库：非整除参数（pins=9 的 SOIC 等）生成重复/超量焊盘；`SW` 符号引用不存在的 `HDR-1x3`；SOT-223 的 tab 无电气别名；`CHIP_CUSTOM` 负间距可生成；`makeIC` 左右引脚数不等错位；`makeConn` pins 无上限。
- IO：KiCad 板框只识别 `gr_line`（忽略 rect/poly/arc，乱序成锯齿）；`(drill oval ...)` 被当 SMD；导出 via 忽略 `layers`（盲埋孔）；导入无版本迁移；写盘非原子；`parseSExpr` 无深度/长度限制；`guessFootprint` 正则无锚点（`CRYSTAL0805` 会命中 `0805`）。
- 3D：OBJ 只翻转 Y（面绕序反转、无法线）；B 面元件体不镜像；只导出表面走线（内层/zone/丝印缺失）；无 STL/STEP；`THREE` 模块加载时捕获（懒加载无效）；resize 监听不清理；非索引几何。
- 渲染/交互：旋转焊盘命中用未旋转 AABB；丝印命中固定框；框选要求全顶点在框内（与行业交叉选择不符）；`_snapshot` 空操作 pop 的健壮性；异步 autoroute 期间可编辑（重入）；实时 DRC 全量重算。
- 主进程：`exportFiles` 重名覆盖/ZIP 平铺/无大小限制；`loadProject` 清单可目录穿越读；`importFile` 大文件整体 `JSON.stringify` 进 `executeJavaScript`；`exportTextFile` 不建目录（已修一半：现会创建）等问题按"路径安全"统一加固；CAD/EDA 文件对话框在 VM 模式下只能选宿主路径（已通过路由兜底报错，建议补默认目录指向工作区镜像）。
