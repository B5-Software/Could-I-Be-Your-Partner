# VM 快速启停

设置 → 本机与虚拟机 → **VM 快速启停**，默认开启。GUI、TUI、WebUI 使用同一个后台与偏好。停止 VM 或正常退出后台时保存运行状态；关闭开关后正常关机。首次启动仍需完整开机。

- KVM / TCG：通过私有 stdio QMP 通道保存 qcow2 内部快照，包含内存与设备状态。没有对外开放的监控端口。
- Windows WHPX / macOS HVF：优先使用来宾 Linux 的磁盘休眠，保留硬件加速。WHPX 不支持完整迁移，不能直接使用 QEMU 内存快照。此路径要求支持休眠的内核、ext4 根文件系统和足够的空间。
- 专用休眠交换文件在 VM 内创建，需要约分配内存大小加 256 MiB 的虚拟磁盘空间。快照和休眠耗时取决于实际内存与磁盘速度。
- SSH 恢复密钥使用操作系统安全存储加密。安全存储不可用或后端不支持保存时，显示原因并正常关机，不保存明文恢复密钥。
- 状态只有一次使用机会。QEMU、镜像、内核、CPU、内存、网络配置或磁盘身份变化时不重放旧状态。恢复失败自动冷启动；工作区磁盘保留。
- 冷启动明确禁用过期的来宾休眠恢复；恢复完成重新连接 SSH、校正来宾时间，并通过现有机制同步主机工作区和主题。

Windows 实机隔离测试（WHPX，2 vCPU / 2 GiB，full 0.3.1）：冷启动约 35 秒、保存约 4 秒、恢复约 12 秒。验证了跨实例恢复相同启动 ID、保留运行中的进程、磁盘文件不丢失、无效状态回退，以及关闭开关后正常关机。这是该次测试结果，不保证所有设备达到相同速度。

手动原生验证：

```powershell
npx electron tests/integration/vm-quick-resume.cjs <VM资源目录> full 0.3.1
```

测试只借用只读镜像与 QEMU，创建独立临时可写磁盘，不操作用户正在使用的实例。
