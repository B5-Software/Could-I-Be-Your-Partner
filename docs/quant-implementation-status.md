# Agent 钱包与专业量化：实现和验收进度

更新于 2026-11-18。量化工作台从 `v1.10.0-alpha.2` 起默认可用。实盘仍需逐笔审批或用户显式授予自动执行权限。

## 当前接入情况

原生 PAPER 增加限价 IOC 和 FOK。现有仅挂单 GTC 仍为默认。立即成交按已观测 L2 深度逐档计算并保存来源序列，原子提交成交、费用、资金和余量撤销，支持重启后按原操作 ID 对账。GUI / WebUI、TUI 和量化 Agent 共用执行。IOC / FOK 当前使用即时盘口模型。

开发版的资产总览支持主动发现 ERC-20。按注册地址的双向标准转账扫描已最终确认的区间，历史分页固定锚点，并复核候选的证据区块和余额。GUI / WebUI、TUI 和 Agent 共用查询。用户选中后可加入跨前端共享的追踪列表。覆盖取决于扫描范围与节点日志支持。

1.10.0-alpha.5 增加组合成交损益。Base / Base Sepolia 实盘计划的 WETH / USDC 成交按各成员钱包分别做先进先出配对，输出已匹配的 USDC 毛损益、待配对数量、证据缺口和 ETH 费用。Base 主网可按交易区块补齐历史报价，参考折算费用并计算扣除配对兑换费用后的损益。GUI、WebUI、TUI 与量化 Agent 通过同一后台读取。范围限于本应用已核对的实盘计划成交。

Base / Base Sepolia 支持为组合中的一个代币设置 ERC-20 授权总额度上限。签名前由原生签名器核对与当前操作绑定的证据，广播前由共享后台重新核对。基准快照包括已发现的授权，检查另查近期日志、本地未结算授权和本次对象。Permit2 外层额度计一次。手动降低额度或归零仍可通过这项上限检查。外部交易、未提交许可和任意合约副作用仍在该控制范围之外。

Base / Base Sepolia 组合可保存带区块哈希和 SHA-256 引用的链上授权快照。三端和量化 Agent 共用最近扫描、历史补扫和已知候选复核。汇总按钱包余额及 Permit2 共享外层额度去重，并标出未完整扫描或读取失败的结果。历史快照可按精确授权对象发起实时人工复核。持续监控由用户从完整快照启用，跨后台重启保存区块进度、最新证据和 30 条变化记录。读取失败保留进度，区块重组导致基准失效时要求人工复核。全链索引与离线签名记录仍待实现。

Base 主网组合支持人工设置 USD 权益下限。原生组合修订持久化门槛，签名时要求与交易、操作和当前组合修订绑定的近期复核。宿主对同区块的 ETH、WETH 和 USDC 扣除已知本地待结算输入和费用后估值，签名前与广播前独立读取。低于下限、报价失效或资金影响未知时阻止操作。三端可配置及复核，Agent 可读取。覆盖范围以本应用交易为限，链外敞口与历史损益仍待接入。

Base / Base Sepolia 增加固定时间窗 TWAP 和历史成交量加权 VWAP。首次启动将窗口锚点落盘，原生调度用单调时间推进，上一段待最终确认期间跳过已经关闭的窗口。跳过份额和已最终确认份额分别记录。钱包领取时取得本窗口剩余时间，签名和广播前复核，路由交易附带窗口内的链上截止时间。最终确认后的串行调度仍可选。GUI / WebUI、TUI 和 Agent 均接入调度选择和历史。模式继续使用单钱包单待确认命令，可能部分成交。并行执行和其他交易场所适配仍在后续范围。

计划及逐段记录增加最终确认回执对账。钱包持久化与交易哈希及区块哈希绑定的净转账和已知费用，计划按代币最小单位汇总实际支出、到账及成交覆盖率。费用分列 L2 执行 Gas、L1 数据费和运营费，覆盖批准及最终确认失败的交易。运营费按原区块哈希读取 GasPriceOracle，三项费用覆盖所有最终确认交易时显示合计。签名前的费用预算按 Gas 上限计入运营费估算。隔离 Anvil 验收用变化的模拟费率区分原区块与最新区块，并核对锁定钱包补账前后的 nonce。Base 和 Base Sepolia 的已最终确认区块均通过公开 RPC 只读查询。[GasPriceOracle 接口](https://specs.optimism.io/protocol/isthmus/predeploys.html#gaspriceoracle)

结束且成交回执齐全的计划支持同期市场 VWAP 对比。系统按首末成交区块读取同一池的成交，核对本计划各笔的区块、方向和金额并剔除这些交易。基准随区块和成交证据保存，钱包证据不足时隐藏，补齐后恢复。隔离 Anvil 验收得到实际均价 2,000、同期市场 VWAP 1,950 USDC/WETH 和 +256.41 bp。卖出方向、金额不匹配及无外部成交由专项测试覆盖。

首次启动把池内边际价和对应区块证据写入原生账本。恢复和重启沿用原始快照。已核对成交以两种代币的原子单位计算相对启动价的 USDC 成本和基点。隔离 Anvil 验收使用 1,975 USDC/WETH 的启动价、2,000 的实际买入均价，得到 +0.05 USDC 和 +126.58 bp。验收另覆盖报价期间停止、过期快照拒绝及原始启动价恢复。Windows x64 原生资源 SHA-256 为 `1d1eba67cb3aee06664353e0c1361ae32a58709c0b7bc002a7caaa97814ec6e8`。

原生实盘计划支持固定的启动价最大不利偏离。宿主将各段相对限额向上取整为最低输出，合并绝对输出下限及报价滑点后写入 Router02 交易，并在签名前和广播前验证。隔离 Anvil 已覆盖报价超过相对限额时停止于代币授权前，以及签名后报价仍在普通滑点内但超过相对限额时阻止广播。Windows x64 原生资源 SHA-256 为 `7117bc89d0067ec3965a03c61c2e714bcf4ff4341fcf41e99f7061af9500abdc`。

Base 和 Base Sepolia 钱包在签名前及广播前重新核对费用。两项附加费来自同一当前区块，并与已确认的 Gas 上限和原费用预留比较。预留不足或无法取得有效新报价时停止这笔交易，计划记录费用原因。隔离 Anvil 分别在签名期间提高运营费和 L1 数据费，核对兑换余额、链上 nonce、未发送状态及原生签名 nonce 的人工恢复。手动审批专项覆盖签名前停止、报价过期和预留边界。

源码及打包后台均通过隔离 Anvil 验收。TWAP 的第二个窗口关闭后完整保留跳过金额。VWAP 读取合约发出的四笔最终确认成交，固定 25%／0%／75% 权重，实际扣款合计 4.000001 USDC。重启后仍可查看原始成交量证据。验收另覆盖签名期间到期拦截、实际交易 calldata 中的截止时间。原生测试覆盖时钟回拨、过期领取、持久记录、按原时间表恢复及 128 位输入的精确分配。Windows x64 原生引擎资源 SHA-256 为 `b1d4d9c614302b11cc2fce7512f3fcc9e15f5cdcaad5ca3ebdc272204bf4718c`。

Base / Base Sepolia 的串行实盘拆单增加可选最低总输出，买入以 WETH 计量，卖出以 USDC 计量。原生引擎以 256 位乘法计算每段比例并向上取整，计划、发件箱和重放保留整数金额。后台校验分配，将每段限制与滑点下限中较高的一项写进 Router02 调用，复核签名交易后按原参数广播。报价不满足时暂停。钱包签名前及广播前都用最新链状态模拟实际调用。GUI / WebUI、TUI 和 Agent 可设置或查看，Agent 单次兑换也可传最低输出。[Uniswap v3 路由合约](https://github.com/Uniswap/swap-router-contracts/blob/main/contracts/V3SwapRouter.sol#L85-L106)

隔离 Anvil 已覆盖报价低于限制时无授权交易、成功交易的实际 calldata 与向上取整一致、签名期间把路由价格改差后广播被拦截。对应批准及原生回执可核对。源码和打包后台均通过。Windows x64 原生引擎资源 SHA-256 为 `e06c6ade95422ef225755195975e9a64baeaf8e0c6da3b0c342680b3998d21de`。最低输出约束代币到账，链上费用另计。其他组合风控见下文。

内置浏览器与本机 Chromium 扩展支持网站提出添加 EVM 网络的请求。GUI / WebUI 和 TUI 的应用连接页先显示站点、链 ID、币种与建议节点来源，用户填写可信 RPC 后核验链 ID、创世区块和签名能力，再确认保存。网页只能提供网络建议，后台拨出的请求使用用户确认的节点。网络保存、账户连接和切换是独立动作。切换保留已连接账户，并复核目标网络版本。旧链上的待处理请求会随切换取消。验证覆盖关闭页面中止节点核验、已登记网络防覆盖，以及 Chromium 使用新登记的隔离链完成登录与人工交易。[添加网络规范](https://eips.ethereum.org/EIPS/eip-3085) · [切换网络规范](https://eips.ethereum.org/EIPS/eip-3326)

源码和打包后台均通过 Chromium 内置浏览器与扩展验收，覆盖保存后独立切换、`chainChanged` 事件及旧请求在其他链被拒绝。打包后台还通过实际 Agent 在隔离链的手动和授权自动执行验收。完整检查 865 项现代测试通过、3 项跳过，389 项兼容测试通过。日志见 `.cache/wallet-site-networks-*.log`。

本机 Chromium 浏览器扩展已接入共享钱包后台，`npm run build:wallet-browser` 可生成未打包安装目录。GUI / WebUI「钱包 → 浏览器扩展」和 TUI `/wallet` 可开启、停止、生成一次性配对地址、核对浏览器指纹及撤销。用户可为浏览器配置命名。浏览器配对、站点授权和交易／消息签名三次分别复核；同一站点在不同浏览器配置或内置浏览器中的授权互不通用。

扩展仅通过回环 WebSocket 连接。双方以 P-256 签名验证握手和消息，服务端身份使用系统加密存储，扩展私钥为不可导出的 WebCrypto 密钥。停用会终止连接、关闭在途文档权限并防止迟到启动，撤销先切断权限再保存。存储失败可在本次运行内维持停用或撤销，需重试写盘才会跨重启生效。断线不自动重送。Chromium 的同一文档重送同一交易 ID 复用原哈希，不再次签名或广播；同一签名 ID 跨连接不能再次拿到签名。新请求 ID 仍需单独批准。

## 原生执行方向

新增 Base 定时拆单发件箱基础层：固定模板和不可变计划绑定钱包 / 链、输入代币最小单位总额、段数、间隔、滑点、池费、配置摘要及授权标识。计划、领取、回报和金额预算与现有原生账本共用 WAL。分配余数使用整数；一次只保留一段未结算命令，同一钱包 / 链存在运行或待核实命令时不能另启计划。授权标识只用于绑定元数据，原生进程仍没有签名、网络或钱包权限。

实盘调度支持最终确认后计时和固定时间窗两种模式。两者由单调时钟驱动，无逐笔 LLM 调用。固定时间窗按首次启动的原始时间表跳过已关闭窗口。领取使用持久标识，已领取后崩溃或停止保留待核实状态。已入块和 safe 回报仍需最终确认。全局暂停和后台关闭会持久暂停计划。

已通过 52 项 Rust 测试和零警告 clippy；当前 Windows x64 受管资源的 20 项真实进程测试通过，包含定时、精度边界、停止 / 重启、领取冲突、证据保护、原生全局暂停、实盘专用暂停及离线回放隔离。源码和打包 Node 后台均验证私有发件箱恢复；通用前端请求和 Agent 工具不能上报成交。完整检查为 714 项通过、3 项跳过及 388 项兼容测试通过。

发件箱现已连接共享后台的 WalletService 和 Agent 工具 quant_live_execution，提供项目内创建、启动、停止、分页历史及只读对账。每段固定启动授权、配置摘要和逻辑操作 ID；钱包队列在准备、签名返回和广播前检查所属计划与当前权限。停止、全局暂停、配置变化、撤权或延迟启动回调不能恢复旧派发权限。模型不能伪造成交、授予自动实盘权限或单独批准计划内交易；计划启动仍须由用户先在钱包设置阅读警告并确认自动实盘权限。

批准代币和兑换共用计划的累计预估费用预算，钱包记录跨重启保存该作用域；预算包含失败 / 未发送尝试的保守估计，不冒充 Base L1 费用的链上硬上限。批准已完成而兑换未发送时使用中止回报，保留已有链上授权和费用记录。未知广播结果只对账；钱包锁定或用户撤权不阻止只读恢复。

源码和打包 Node 后台均已用原生调度器、真实加密签名器和隔离 Anvil 验证两段代币转移、精确批准、最终确认、签名期间停止 / 撤权 / 全局暂停 / 配置变更、预估费用不足、隐藏确认和锁定钱包重启对账。合约使用源码和字节码均校验的测试夹具。CI 接入同一验证，当前本地只验证 Windows x64。GUI / WebUI 共用实盘计划组件，TUI 使用同一后台和三语标签。隔离 Electron 检查成交量权重预览、创建不授权、无交易派发、刷新不打断输入及关闭不改变计划状态。其他执行协议和硬性组合风控仍待接入。

钱包实盘广播另补了授权竞态修复：钱包解锁会话和自动执行授权分别保留代次；签名前、签名返回后、写入交易哈希时及实际调用广播 RPC 前再次检查。锁定立即清除主机授权；旧解锁回调不能复活已锁定的钱包，也不能清掉较新的有效解锁。撤权先写独立的持久暂停记录，再排队更新主钱包记录，避免普通请求卡住或中途重启恢复旧自动权限；暂停记录损坏时关闭钱包能力。

发送前中断记录为确定未广播；广播 RPC 已调用后的中断保留交易哈希和结果待核实状态，不自动重发。GUI / WebUI / TUI 增加对应的三语说明；Agent 提示词明确区分撤权和链上撤销，不得靠换钱包或操作 ID 绕过撤权。已用真实加密签名进程和本地 Anvil 分别验证发送前撤权无转账、节点已接受后撤权仍只有一笔转账且可对账，并覆盖跨重启恢复；这不代表独立连续策略实盘桥已经完成。
