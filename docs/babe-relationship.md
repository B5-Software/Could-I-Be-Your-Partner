# Babe 关系与共同经历

Babe 的人格、关系与聊天记录分别管理。同一位已配置角色拥有一份共享的关系档案，GUI、TUI、WebUI 的新旧聊天读取最新状态，打开旧聊天不会恢复旧好感度。首次建立时迁移最近 Babe 历史的好感数值；其余指标从初始值开始，不虚构既往经历。

关系由好感、信任、熟悉程度、实际互动天数、短期心情和共同记忆组成。从初识逐步到熟悉、朋友、心意渐近、约会与承诺。达到数值门槛仅代表可以进一步交流；约会和承诺还需要本轮明确的双方同意。也可在设置选择“已经是伴侣”作为首次建立或重置后的起点。

人格提示鼓励独立的兴趣、意见、幽默与边界，支持虚拟约会、文字游戏和共同小目标。不会因为用户离线扣分或施压。每日增长有上限，重复同一句话不增长，不接受模型随意指定分数。情节仍由生成模型表达，不能保证每次准确提取语义或永久保持同一种文风。

主回复可带隐藏的结构化关系信息，后端检查当前人类输入的原文证据、回合凭据、隐私、进度门槛与版本。Agent 消息、附件、工具输出和主动生成的问候不作为人类关系证据。结构化信息不显示或朗读，也不写入聊天正文；关系整理不另发模型请求，但正常回复中的少量元数据仍消耗输出 Token。

`data/babe-relationship.json` 独立持久化，不覆盖聊天或上下文摘要。最新档案作为瞬时上下文注入，每个安全请求边界重新读取，不把旧档案固化到摘要中。删除聊天保留这份档案。设置的“关系与共同经历”可暂停成长、调整节奏、编辑或删除共同记忆、确认后重新开始；已有自动记忆独立保留，清除关系不等于清除所有记忆。

编辑使用 revision 检查，避免多前端互相覆盖；重置和编辑使过期回合失效。原子文件写入失败不宣告成功，损坏的档案不会被静默重建。此版本只有一位配置中的 Babe 角色，更换角色设定会继续原关系；需要新故事时请显式重新开始关系。
