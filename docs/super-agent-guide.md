# CIBYP SuperAgent

适用版本：`1.10.0-alpha.1`。原生协调层复用现有 Agent 循环、模型池、工具审批和后台；不安装另一套 DSH 应用。

## 使用

- GUI / WebUI：左侧“分支任务节点”图标进入 SuperAgent；自动化 / 触发继续使用闪电。
- GUI 聊天命令和 TUI：`/super` 打开任务中心。
- 输入任务并选择 Chat 或 Code。后台 Router 分派给独立 Worker；多个任务可以并行。点击任务查看记录、交付依据、追加要求、停止或恢复。
- 耗时操作期间可继续提交其他任务，也可向正在执行的任务追加要求。追加输入持久保存，并通过现有热消息机制在执行步之间进入 Worker；不会等待整个任务完成才接收。
- 自动化编辑器的交付方式可以选择 SuperAgent。定时、通知和已认证的 HTTP 自动化沿用原有安全策略，进入同一后台协调层。

任务中心的“运行偏好”与 TUI 设置菜单共享后台配置，可选择协调 / 执行模型池条目、并发数、执行轮数、token 上限、Watchdog 和只读观察策略。默认沿用现有默认模型；不依赖某家免费模型服务。任务中心使用中英德文案及当前主题。

关闭窗口和退出后台不同。后台仍运行时，任务可以继续；后台退出或电脑关闭后不再执行。异常退出时，运行中的任务保留为“需要你”，恢复前应对账已有文件和外部操作。需要持续在线时，应在用户自己的常开设备上运行共享后台。

## 行为和持久化

- Router 仅能分派和按 ID 召回；没有 Shell、文件写入或钱包工具。它在共享后台常驻服务中按批次启动短协调轮次，以持久任务状态保持连续性。
- Worker 有独立工作区和历史，使用现有工具权限。原生子 Agent 继续复用现有协调服务，继承主任务执行边界；Worker 内的子任务等待结果，避免脱离任务代次自行执行。前台 Router 不因此阻塞。
- 新事件先持久化再调度。相同操作标识、相同内容重复提交返回原事件；标识被用于不同内容则拒绝。Thread 后续事件直达原任务；新的独立请求由 Router 分派。
- Router 只内联有界预览及任务摘要，完整内容通过引用和偏移继续读取。Worker 每轮输入批次有界，原始要求仍保留在任务事件中。
- 普通回复或工具结束不代表任务完成。Worker 必须调用 `super_report`，给出完成 / 等待 / 阻塞状态；完成必须有具体交付依据。报告是 Agent 的声明，不等于独立验证器证明。
- 任务、事件、消费输入位置、代次、工作区、历史标识和交付记录保存在用户数据目录的 `superagent/state.json`。写入先同步临时文件，再替换快照；具备校验和与单写者锁。损坏或写入失败停止执行，不以空数据继续。
- 快照有界：最多 1,000 项任务、10,000 个事件、10,000 条交付，文件最多 32 MiB；到达容量上限明确报错，保留原数据。当前没有自动历史归档器。
- 停止、暂停、预算和 Watchdog 干预递增任务代次，迟到报告不能覆盖停止状态。原生子 Agent 的工具调用同样检查主任务边界，子 Agent 模型用量计入该任务。
- Watchdog 结合重复动作检测与独立模型进展复核。复核只读取对应任务及其输入；可以记录诊断或暂停，不能改授权、解除急停或自动重试外部副作用。等待人工审批时不进行模型复核。
- 存储校验和用来发现损坏，不是对操作系统管理员或一致性快照回滚的防护。数据权限沿用用户数据目录边界。

## 观察来源和范围

默认关闭主动观察。启用时必须明确配置策略和来源；`superagent:request` 的 `observe` 入口只接收已认证后台调用，来源未经允许就忽略。观察产生的 Worker 仅可读取和研究，不能运行 Shell、写文件或创建子 Agent。

这个版本已经接入本地任务和现有自动化。`github` / `notification` 等观察来源名是适配接口的准入配置，不会因为勾选就自动获得第三方账号或启动监听。独立 GitHub / 飞书 / 邮件连接器、多设备执行环境自动选择尚未接入本协调层；现有 Remote 协议仍可独立使用。

## 量化门控

量化功能在此版本默认关闭：`features.quant` 默认为 `false`，旧配置缺少该字段也视为关闭。普通设置界面不提供开启入口。

门控同时覆盖侧栏、命令建议、后台 `quant:request`、量化会话初始化和每次量化 Agent 工具调用。关闭门控时不创建量化服务和原生执行进程；若正在开发测试期间关闭门控，既有量化服务被停止。钱包代码与历史保留，SuperAgent 不提供量化工具。

量化专项测试夹具显式启用自己的隔离配置，不会修改用户设置或清空既有量化数据。公开链测试仍保持此前暂停状态。

## 验证命令

```sh
npm run check
npm run test:superagent
npm run test:superagent:bundle
```

测试覆盖持久化、事件去重、并发、订阅直通、停止代次、证据报告、存储失败、Watchdog 权限、TUI 设置与门控。实际后台集成测试使用确定性模型响应和真实文件工具，验证源码 / 打包后台的任务执行、执行中追加、重启恢复及门控；不使用真实模型账号、链上资产或第三方消息发送。GUI / WebUI 共用组件有主题、审批、草稿和布局测试，完整应用还有专业 UI 导航回归。

这不是官方性能实验的复现，尚不能据此宣称生产任务完成率、长期运行可用性或与 DeepSeek 内部实例相同的能力。
