# 1.9.0-alpha.26 发布审计

范围：从 `c3990b6` 开始积累的桌面界面、共享会话、消息编辑、工作目录、模型连接、凭据和 VM 启停改动。版本从 `1.9.0-alpha.25` 递增为 `1.9.0-alpha.26`；独立 npm 启动器仍为 `1.0.1`。

## 审计修复

- 消息删除：只有历史原子写入失败才回滚上下文。写盘成功后，清理目录索引更新失败不能使内存恢复为旧记录。
- 目录清理：在遍历内部历史目录前检查实际工作目录，拒绝符号链接和 Windows junction；删除别名和 VM 导入目录前检查所属根目录。删除只使用非递归 `rmdir`。
- Claude 注销：阻止新凭据租用，等待已排队的加密、SDK 取消及最后一次刷新完成，再删除当前账号目录。不能只依赖排队期间暂时为零的租用计数。
- Claude 退出：退出期间准备中的登录不能再启动授权子进程，已取消的请求不能在获取凭据后继续启动状态查询。
- VM 保存：停止后台同步循环启动下一组传输，拒绝关闭过程中的新目录导入，并等待已有传输释放后再保存状态。

## 验证

- `npm run check`：ESLint、Prettier、TypeScript 均通过；564 项单元测试通过、3 项平台相关测试跳过；388 项旧回归通过。
- `npm run test:desktop`：桌面初始化与 Splash、共享后台所有权、WebUI、VM 桌面、真实 TUI 键盘/鼠标与退出。
- GUI/WebUI 界面和真实 Code-OSS 集成；共享后台在青春和专业两种界面中的完整回归。
- Claude GUI 登录、模型池、订阅推理适配、用量、重新授权、隔离注销；DSH 模型插件和 Babe 关系回归。订阅服务使用隔离模拟授权，不消耗真人付费额度。
- 发布说明及六平台产物重跑测试；`npm audit --audit-level=high`。
- Windows WHPX：独立临时磁盘上的真实 Linux 休眠、跨实例恢复、运行进程与文件保留、无效状态冷启动回退、关闭快速启停后的正常关机。另已验证真实 QEMU TCG 的 QMP 保存、读取和删除快照。

## 保留的限制

- Codex 用量的独立浏览器授权、只读导入、签名/账号校验、刷新和手动重置协议通过模拟验证；尚未替用户完成真人授权，不能据此声称已读取该用户的实际额度。
- OpenCode 免费模型在线测试返回服务端出口 IP 限制。此版本更新兼容层，但不声称解除服务端的免费访问限制。
- 依赖审计报告为 0 严重、0 高危、10 中危、1 低危。涉及 nut-js/Jimp/file-type、mammoth 的依赖链和 KaTeX；部分上游无可用修复，自动强制修复可能降级主依赖或引入破坏性升级，因此未使用 `npm audit fix --force`。
- 本机验证平台为 Windows；macOS/Linux 的平台行为仍须由 CI 和相应设备确认。macOS HVF 的来宾休眠路径没有在本机实测。

凭据和实际账号信息不进入本报告、测试截图或提交。测试日志及截图位于被 Git 忽略的 `.cache` 中。

## CI 后续修复（alpha.27）

alpha.26 的固定标签保持原提交。CI 揭示的修复通过 alpha.27 发布：

- 凭据模块改为由桌面宿主注入系统加密适配器，移除共享 Node core 对 Electron 的静态依赖；无系统加密后端时仍拒绝明文回退。Node core 实际打包通过。
- 重新生成 IPC 能力清单，并在 `npm run check` 增加清单一致性检查。
- 界面测试通过 Chromium 媒体偏好模拟，分别验证动画开启、应用全局关闭及操作系统减弱动画，避免 Windows runner 的系统设置改变断言前提。
- Tor 固定包增加[官方归档站](https://archive.torproject.org/tor-package-archive/torbrowser/)回退，继续校验原锁定版本、大小与 SHA-256。已实测 Windows x64、macOS x64/arm64、Linux x64/arm64 的下载校验与解包；Windows ARM64 共用锁定的 Windows x64 包。

alpha.27 本地验证：566 项单元测试通过、3 项平台相关测试跳过，388 项旧回归通过；Node core 打包及直接加载、GUI/WebUI（含强制系统减弱动画）和 Claude 登录注销集成通过。
